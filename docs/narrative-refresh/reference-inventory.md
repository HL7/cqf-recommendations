## External URL verification

The link check is anchored to baseline commit `320b164065d795dd0b7ab9ab313a67f129e06dc7`, not the concurrently changing working tree. The baseline contains 57 Markdown pages. The scan found 357 distinct URL-like strings overall; 74 URLs unique to `changes.md` were excluded as historical. Active narrative contained 283 distinct URL strings across 383 line occurrences. Five targets were excluded from HTTP checking: two Markdown destinations contain literal backslashes before ampersands (Google Docs and a Goodwin LibGuide), and three `example.org` URLs in an interactive CDS sample are placeholders. Nine additional DOI/WHO URL-like strings appear in malformed Markdown labels or punctuation, not as destinations; they are recorded separately. The 278 remaining distinct URLs were checked with unauthenticated GET, redirects followed, concurrency capped at 6, and 5-second connect/15-second read timeouts. The exact source URL, pages and lines, final URL, response, redirect chain, timestamp, and classification are in [`link-checks.json`](link-checks.json).

Current baseline outcomes: 156 reachable, 28 redirected, 38 not found, 54 blocked, 0 timeouts, and 2 errors. Statuses describe endpoint reachability only, not whether content is current or semantically equivalent. A 403/429 is blocked rather than dead; a 200 response can still serve a challenge. DOI/publisher access restrictions do not invalidate citations. This scan used balanced Markdown-destination parsing, HTML `href` extraction, and bare HTTP(S) mentions outside parsed destinations; it may miss malformed Markdown or URLs assembled by templates.
