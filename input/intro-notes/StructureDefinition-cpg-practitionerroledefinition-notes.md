- Practitioner, organization, identifiers, active/period, contact details, availability, and endpoints are prohibited.
- Optional role codes use the preferred common-persona binding. Specialty is supported; any location reference targets CPGLocationDefinition rather than an actual location.
- A CPGCareTeamDefinition can reference this role. Local staffing supplies the separate practitioner and patient-team assignment.
