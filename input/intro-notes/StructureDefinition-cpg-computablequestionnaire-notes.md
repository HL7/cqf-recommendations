- Items and answer options are must-support. An item can carry `answerValueSetSource` and `itemImage`; an answer option can carry `responseImage`.
- These additions do not make the Questionnaire an SDC population, extraction, or adaptive-form profile. Apply the appropriate SDC contracts separately when those capabilities are used.
