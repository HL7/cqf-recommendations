Use Patient `$summary` to obtain the current patient summary as a document Bundle for a selected patient. This can supply a portable clinical overview to a receiving system or a guideline implementation that needs to assemble its patient context.

The operation describes agreed document conventions, such as the International Patient Summary. It does not require every returned document to use one named profile. A patient summary document has a different role from a guideline-specific [case summary](StructureDefinition-cpg-casesummary.html).
