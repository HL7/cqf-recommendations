- The `code` pattern includes `stop-activity`. Inherited Task `intent` is not fixed to proposal; `status` describes this control Task.

- `focus` is required once and restricted to the enumerated CPG activity request, event and Task profiles. The list is not an unrestricted Reference to any resource.

- When carrying out the recommendation, stop the focused activity using its resource-specific allowed states and authority. Stopping is distinct from rejecting the control Task or marking the original record entered in error.
