- The `code` pattern includes `resume-activity`. Inherited Task `intent` is not fixed to proposal; `status` describes this control Task.

- `focus` is required once and restricted to the enumerated CPG activity request, event and Task profiles. The list is not an unrestricted Reference to any resource.

- When carrying out the recommendation, resume the focused activity using its resource-specific allowed states and authority. Confirm that the focused activity can resume; the reference constraint does not guarantee a reversible paused state.
