- Exactly one practitioner reference is required and targets CPGPractitioner.
- Role codes use a preferred binding to CPGCommonPersonaVS; the binding is not required and does not make the code mandatory. Identifier use/value are supported.
- Role identification does not replace the local authorization decisions governing clinical actions.
