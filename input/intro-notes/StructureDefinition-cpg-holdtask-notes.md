- The `code` pattern includes `hold-activity`. Inherited Task `intent` is not fixed to proposal; `status` describes this control Task.

- `focus` is required once and restricted to the enumerated CPG activity request, event and Task profiles. The list is not an unrestricted Reference to any resource.

- When carrying out the recommendation, pause the focused activity using its resource-specific allowed states and authority. Some permitted focus types have no on-hold state; the reference constraint does not create one.
